This project covers the modification of Integrated Information Theory in its fourth edition. The modification itself is rooted in creating a framework that is able to be applied to the brain-computer interface (BCI). It proves that IIT 4.0 can be grounded in physical substrates by providing new exclusive formulas based on the characteristics of the BCI. It is better to bring real BCI characterists to determine Phi of the real world technology, though hypothetical results are possible as well, the model counts them too.
